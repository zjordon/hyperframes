## 1. 快速开始

### 1.1 环境要求

| 要求 | 版本/说明 |
|------|-----------|
| Node.js | >= 22 |
| FFmpeg | 需单独安装并加入 PATH（本地编码必需） |
| Chrome/Chromium | 无需手动安装 —— CLI 自带 `npx hyperframes browser` 管理内置浏览器 |
| Bun | 仅两类场景需要：① 仓库贡献者（workspace 操作）② 构建 AWS Lambda handler ZIP（bun >= 1.3）。终端用户使用 CLI 不需要 bun |

安装后运行 `npx hyperframes doctor` 可一键验证 Chrome / FFmpeg / Node 是否就绪。

### 1.2 安装

```bash
# 方式一：npx 直接使用（推荐，无需安装）
npx hyperframes init my-video

# 方式二：全局安装
npm install -g hyperframes

# AI agent 路线：Claude Code 插件
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

# AI agent 路线：独立技能（交互选择 Core Skills 组）
npx skills add heygen-com/hyperframes
```

### 1.3 快速运行

```bash
npx hyperframes init my-video   # 脚手架：index.html + hyperframes.json + compositions/
cd my-video
npx hyperframes preview         # 默认 http://localhost:3002
npx hyperframes render          # 输出 MP4（-o output.mp4 指定路径）
```

> 本地渲染不消耗 HeyGen credits（docs/quickstart.mdx 注明）。

## 2. 配置说明

### 2.1 配置文件：`hyperframes.json`

由 `init` 写入项目根目录，`add` 读取；没有 hyperframes.config.* 文件。缺省字段用默认值，删除该文件即回退默认（schema: docs/schema/hyperframes.json）。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `registry` | string | 官方 registry | 自定义 registry URL |
| `paths.blocks` | string | 默认目录 | `add` 安装 blocks 的落盘位置 |
| `paths.components` | string | 默认目录 | 安装 components 的落盘位置 |
| `paths.assets` | string | 默认目录 | 资产目录 |
| `media.autoProxy` | boolean | true | 预览媒体代理开关 |

项目结构约定（docs/concepts/index.mdx）：`index.html`、`hyperframes.json`、`compositions/`（场景）、`assets/`、`renders/`，可选 `BRIEF.md` / `STORYBOARD.md` / `SCRIPT.md` / `frame.md`。

### 2.2 环境变量

| 变量 | 必需 | 说明 |
|------|------|------|
| `HYPERFRAMES_RENDER_DETACHED` | 否 | `=1` 时 render 在启动进程退出后继续运行 |

## 3. 主要功能

### 3.1 Composition（组合）编写 —— HTML 即视频

**说明**: 用 `data-*` 属性声明时间轴，GSAP 声明动画；渲染时由无头 Chrome 逐帧 seek + FFmpeg 编码，输出确定性视频。

README "How It Works" 最小示例：

```html
<div id="stage" data-composition-id="launch" data-start="0" data-width="1920" data-height="1080">
  <video class="clip" data-start="0" data-duration="6" data-track-index="0"
         src="intro.mp4" muted playsinline></video>
  <h1 id="title" class="clip" data-start="1" data-duration="4" data-track-index="1">Launch day</h1>
  <audio data-start="0" data-duration="6" data-track-index="2" data-volume="0.5" src="music.wav"></audio>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
  <script>
    const tl = gsap.timeline({ paused: true });
    tl.from("#title", { opacity: 0, y: 40, duration: 0.8 }, 1);
    window.__timelines = window.__timelines || {};
    window.__timelines.launch = tl;
  </script>
</div>
```

**data-* 属性语义**:

| 属性 | 说明 |
|------|------|
| `data-composition-id` | 组合根节点 ID，须与 `window.__timelines[<id>]` 注册名一致 |
| `data-width` / `data-height` | 画布尺寸（根节点必填） |
| `data-start` / `data-duration` | 元素时间轴起点/时长（秒） |
| `data-track-index` | 轨道号 |
| `data-volume` | 音频轨音量 |
| `data-no-timeline` | 声明该组合无动画时间线（跳过 45s 轮询等待） |

**两条铁律**: ① 定时可见的元素必须加 `class="clip"`，否则恒可见；② 动画 timeline 必须 `paused: true` 并以精确 composition ID 注册到 `window.__timelines` —— 媒体播放由框架接管，脚本中禁止 `play()/pause()/currentTime`。

### 3.2 CLI 命令

**说明**: 创建 → 校验 → 预览 → 渲染 → 发布的完整闭环。

```bash
npx hyperframes init my-video                  # 脚手架
npx hyperframes add flash-through-white        # 从 catalog 安装块/组件（如 add data-chart）
npx hyperframes lint ./my-composition --verbose # 静态结构检查（--json/--verbose）
npx hyperframes check --json                   # 运行时门禁：lint + 运行时错误 + 布局 + motion intent + WCAG 对比度
npx hyperframes snapshot --at 0,3,8            # 抓关键帧截图（--zoom 高密度局部裁剪）
npx hyperframes preview --port 4567            # 预览（非交互 shell 自动转 managed preview，
                                              #   支持 --background/--status/--stop/--list/--kill-all）
npx hyperframes render -o output.mp4           # 渲染（-c 指定 composition；--docker 固定环境）
npx hyperframes publish --public               # 发布（默认私有；--update/--space 可选）
npx hyperframes doctor                         # 环境体检：Chrome / FFmpeg / Node
npx hyperframes compositions                   # 列出组合并解析时长
npx hyperframes browser                        # 管理内置 Chrome/Chromium
npx hyperframes benchmark / info / upgrade --check / normalize-audio / docs
```

## 4. API 接口

本项目对外的"API"主要是三类（无 REST 服务需自建）：

| 接口 | 形式 | 说明 |
|------|------|------|
| `hyperframes` CLI | 命令行 | 见 §3.2，完整参考 docs/packages/cli.mdx |
| `<hyperframes-player>` | Web Component | 可嵌入网页播放组合（@hyperframes/player 包） |
| @hyperframes/sdk | TypeScript 库 | 无头组合编辑引擎（session/adapters），适合构建自己的编辑器 |

## 5. 常见问题

来源: docs/guides/troubleshooting.mdx

### Q: 排查渲染问题的通用路径是什么？
A: `doctor` → `lint` + `check` → `snapshot --at 0,3,8` 看关键帧，再定位具体环节。

### Q: 报 "No composition found"？
A: index.html 需含带 `data-composition-id` / `data-width` / `data-height` 的合法根节点。

### Q: 报 "FFmpeg not found"？
A: 按平台安装 FFmpeg（Windows: 下载后加入 PATH），再跑 `doctor` 验证。

### Q: 预览黑屏但渲染正常？
A: 源媒体 codec 浏览器解不了 —— 检查自动代理设置、`doctor`、`lint --verbose`。

### Q: 视频"冻结但盒子在动"？
A: 不要直接 animate video 的 `width/height/top/left`，套一层 wrapper 动 wrapper。

### Q: 每次渲染莫名多 45 秒？
A: 无 timeline 的组合缺 `data-no-timeline` 声明（lint 规则 `missing_data_no_timeline`）。

### Q: 渲染结果与预览不一致？
A: 检查字体 / 远程媒体 / 浏览器特效差异，或用 `render --docker` 固定渲染环境。

### Q: 渲染太慢？
A: draft 质量先出草稿 → `snapshot` 抽查 → 压缩源媒体 / 简化滤镜；调 worker 数前先跑 `benchmark`。
